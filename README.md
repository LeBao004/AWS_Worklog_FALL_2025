## Report Structure

The internship report is organized into the following main sections:

### 1. Worklog

This section records the weekly internship activities from **Week 1 to Week 12**.  
Each worklog describes the tasks completed, knowledge gained, and progress made during the internship.

### 2. Proposal

This section presents the internship proposal, including goals, expected outcomes, and the planned direction for the internship period.

### 3. Translated Blogs

This section contains translated technical blogs related to AWS and cloud computing topics.  
The purpose is to improve technical understanding and documentation skills.

### 4. Events Participated

This section documents the events attended during the internship, including learning activities, community events, and AWS-related sessions.

### 5. Workshop

This section presents the workshop implementation and technical practice.  
The workshop includes several AWS services and setup steps such as:

- Amazon Bedrock
- AWS Lambda
- Amazon API Gateway
- Amazon CloudWatch
- Amazon S3

### 6. Self-Assessment

This section includes personal reflection on the internship experience, skills gained, strengths, weaknesses, and areas for future improvement.

### 7. Sharing and Feedback

This section contains sharing activities and feedback collected during or after the internship period.
